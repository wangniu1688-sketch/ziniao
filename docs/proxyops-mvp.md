# ProxyOps MVP：跨境代理健康管理

## 产品目标

让跨境卖家和小型运营团队一眼知道：哪条代理可用、延迟多少、最近是否频繁掉线、异常从什么时候开始。第一版不承诺“防封”或“IP 纯净”，只提供可验证的连接质量监控。

## 首批用户

管理多条代理、多个店铺的中国跨境卖家及代运营团队。先找 10–20 位真实用户试用，目标是获得 3 位付费用户；不以注册量作为成功标准。

## MVP 范围（只做四件事）

1. 代理台账：新增/编辑/停用 HTTP、HTTPS CONNECT、SOCKS5 代理；密码只在服务端保存，不在列表/API 明文回传。
2. 一键检测：通过代理访问用户指定的 HTTP(S) 检测地址，记录成功/失败、HTTP 状态码、延迟和检测时间。
3. 历史记录：按代理查看最近检测结果，展示成功率与延迟趋势。
4. 异常提示：连续失败或延迟超过用户阈值时标记异常；第一版先站内提示，不接短信/企业微信。

## 明确不做

- 不开发浏览器内核、指纹伪装、MITM 或自动化养号。
- 不做代理商采购/转售，不承诺出口 IP 质量或平台账号安全。
- 不先做复杂团队权限、计费中心和多平台 ERP。
- 不先接代理商专有 API；先支持用户自己录入代理。

## 首版验收

- 能添加并安全保存一条代理配置。
- 一键检测能返回真实连接结果和耗时。
- 检测失败有明确原因，不能把失败伪装成成功。
- 能查看最近 100 条检测记录。
- Windows 客户端可管理代理并展示状态；Web/API 服务端复用现有 Go 架构。
- 有 10–20 名目标用户试用反馈，再决定是否加入自动巡检、告警和订阅收费。

## 变现验证

先人工联系目标用户，展示真实检测结果和历史记录。价格测试只作为访谈问题：个人版 ¥29–39/月、团队版 ¥79–99/月；在用户愿意付费前不投入完整支付系统。

## 技术路线

复用现有 Go 代理拨号器（HTTP CONNECT / SOCKS5）和 Tauri Windows 外壳。新增独立健康探测能力；探测请求必须设置超时、限制响应体、拒绝非 HTTP(S) 目标，并且绝不记录代理密码。检测历史后续存入现有 Store/PostgreSQL。
